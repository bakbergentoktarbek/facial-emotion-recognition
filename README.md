# Facial Emotion Recognition — распознавание выражений лица

Бұл веб-камера арқылы адам эмоцияларын анықтауға арналған машиналық оқыту жобасы.

Учебный проект по методичке «Бет-бейнеден эмоцияны тану». Примеры преподавателя
перенесены из DOCX с сохранением комментариев и структуры. Исходный документ не изменён.
Модель классифицирует выражение лица; результат не определяет чувства человека.

## Работа в команде

```powershell
git clone https://github.com/bakbergentoktarbek/facial-emotion-recognition.git
cd facial-emotion-recognition
```

После клонирования установи зависимости и скачай FER-2013. Датасет, `.venv`,
кэш `.wheels`, обученные модели и журналы обучения остаются локальными.
Модель `models/emotion_cnn.keras` передадим отдельно после обучения.

В Git хранится `reports/data_split_seed42.json`: списки файлов train и validation
с путями относительно `data/fer2013`. Используйте это разбиение для сравнения
методов; validation и test не включайте в обучение. Текущий CNN-скрипт воспроизводит
его при seed 42 и указанных версиях библиотек. Для второго метода используйте
те же списки, даже если обучение будет без меток эмоций.

Изменения делайте в отдельных ветках, например `git switch -c feature/web-interface`,
и объединяйте через pull request в `main`.

## Установка (PowerShell, из папки проекта)

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip --isolated install --index-url https://pypi.org/simple -r requirements.txt
.\.venv\Scripts\python.exe tools/check_environment.py
```

Активация среды не обязательна: команды используют её Python напрямую.
В VS Code выбери интерпретатор `.venv\Scripts\python.exe`.
Для точного восстановления текущей среды на Windows можно использовать
`requirements-lock.txt` вместо `requirements.txt`; для Colab используй основной
`requirements.txt`. При повторной установке параметр `--find-links .wheels`
позволяет использовать сохранённые пакеты.
Вместо двух пакетов OpenCV используется `opencv-contrib-python`, который включает
`cv2` и нужен MediaPipe. Gradio ограничен веткой 5.x для примера из методички.
На Windows локальный CPU подходит для камеры; обучение можно перенести в Colab.

## Первый запуск: найти лицо

Запускай самостоятельно, когда готов включить камеру:

```powershell
.\.venv\Scripts\python.exe src/face_detect.py --detector haar
```

`M` переключает Haar / MediaPipe, если MediaPipe доступен; `Q` закрывает окно.
При проблеме с камерой закрой Zoom/Teams и попробуй `--camera 1`.
Кадры этот скрипт не сохраняет. Для сравнения запиши, как работают детекторы при
прямом лице, повороте головы, частичном закрытии лица и слабом освещении.
Шаблон для записи результатов: `DETECTOR_COMPARISON.md`.

## Получить FER-2013

Датасет из методички: https://www.kaggle.com/datasets/msambare/fer2013
Можно скачать архив через браузер. Также доступна загрузка публичного архива без токена:

```powershell
.\.venv\Scripts\python.exe tools/download_dataset.py
```

Если сервер Kaggle потребует вход, используй скачивание через браузер.
Ожидаемая структура:

```text
data/fer2013/
  train/
    angry/ disgust/ fear/ happy/ neutral/ sad/ surprise/
  test/
    angry/ disgust/ fear/ happy/ neutral/ sad/ surprise/
```

Это отдельные папки классов, содержащие изображения. Избегай лишнего вложенного
каталога `fer2013/fer2013/`. Не добавляй датасет и Kaggle-токены в Git.
Если Kaggle CLI уже настроен, альтернативная команда:

```powershell
.\.venv\Scripts\kaggle.exe datasets download -d msambare/fer2013 -p data/fer2013 --unzip
```

Для исследования данных:

```powershell
.\.venv\Scripts\python.exe src/data.py
```

Результат: `reports/class_distribution.png` и `reports/samples.png`.
Примеры выбираются отдельно для каждого класса, чтобы редкие классы тоже были видны.

## Обучение CNN

При фоновом запуске через `tools/start_training.py` PID и команда находятся в
локальном `reports/training_run.json`. На исходном компьютере первый запуск
уже работает; на других компьютерах обучение автоматически не запускается.
Не запускай вторую копию одновременно на одном компьютере.
Текущий прогресс: `reports/status_cnn.json`; журнал: `reports/training_cnn.log`.
После каждой завершённой эпохи сохраняются:

- `models/emotion_cnn.keras` — лучший результат по validation accuracy;
- `reports/training_cnn.csv` — метрики по эпохам;
- `reports/history_cnn.json` и `reports/history_cnn.png` — история и графики.

EarlyStopping останавливает обучение после 8 эпох без улучшения validation
accuracy. При замедлении улучшения val_loss learning rate уменьшается.
Для запуска вручную после завершения текущего процесса:

```powershell
.\.venv\Scripts\python.exe src/train.py --model cnn --epochs 60 --batch 64
```

Настройки выбираем по validation. Test используем для финальной оценки:

```powershell
.\.venv\Scripts\python.exe src/evaluate.py --model models/emotion_cnn.keras
.\.venv\Scripts\python.exe src/webcam_demo.py
.\.venv\Scripts\python.exe src/app_gradio.py
.\.venv\Scripts\python.exe src/game.py
```

Последние команды требуют сохранённого файла модели. Для итоговой демонстрации
используй лучший checkpoint после завершения обучения.
Интерфейс и игра сохраняют казахские подписи из методички. На Windows используется
Arial, либо можно положить `DejaVuSans.ttf` в `fonts/`.

## Карта файлов

| Файл | Назначение |
|---|---|
| `src/config.py` | Пути, классы, цвета, шрифты |
| `src/face_detect.py` | Haar и MediaPipe, сравнение с камеры |
| `src/data.py` | Загрузка данных, разбиение, веса классов, графики |
| `src/model_cnn.py` | Своя свёрточная сеть |
| `src/model_transfer.py` | Пример MobileNetV2, решение по использованию позже |
| `src/train.py` | Обучение и сохранение |
| `src/evaluate.py` | Метрики и анализ ошибок |
| `src/predictor.py` | Подготовка лица и предсказание |
| `src/webcam_demo.py` | Демонстрация модели с камеры |
| `src/app_gradio.py` | Интерфейс в браузере |
| `src/game.py` | Игра «Повтори эмоцию» |
| `tools/extract_examples.py` | Извлечение исходных примеров; существующие файлы не перезаписывает |
| `tools/check_environment.py` | Проверка библиотек и детекторов без включения камеры |
| `tools/start_training.py` | Запуск CNN в фоне с журналом, PID и пониженным приоритетом CPU |
| `tools/fetch_wheels.py` | Загрузка крупных пакетов частями с PyPI, проверка SHA-256 и журнал `.wheels/download.log` |

План на две недели: первая — окружение, данные, CNN и камера; вторая — второй
метод после уточнения, сравнение, интерфейс, игра, отчёт и защита.
