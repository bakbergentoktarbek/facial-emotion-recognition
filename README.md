# Facial Emotion Recognition — бет әлпетінен эмоцияны тану

Веб-камерадағы бет әлпетін жеті санатқа жіктеуге арналған машиналық оқыту жобасы.
Жоба «Бет-бейнеден эмоцияны тану» әдістемесі негізінде жасалған. Оқытушының DOCX
құжатындағы мысалдар бастапқы түсініктемелері мен құрылымы сақталып көшірілген.
Бастапқы құжат өзгертілмеген. Модель бет әлпетін жіктейді; оның нәтижесі адамның
нақты сезімін анықтамайды.

## Жобаның қазіргі күйі

- Жоба бумалары құрылып, оқытушының 11 бастапқы модулі көшірілді.
- Windows үшін орнату командалары мен ортаны тексеру құралы дайындалды.
- Кітапханалар `.venv` ортасына орнатылды (Python 3.11). `pip check` тәуелділіктер
  арасында қайшылық таппады. Кітапханаларды импорттау, бос кадрда Haar және
  MediaPipe детекторларын іске қосу, CNN құру, `.keras` файлын сақтау және жүктеу,
  жеті санаттың ықтималдығын есептеу тексерілді. Бұл тексеру камерасыз, оқытусыз,
  CPU арқылы орындалды. Python файлдарының синтаксисі де тексерілді.
- Орнатылған кітапханалардың нақты нұсқалары `requirements-lock.txt` файлында
  сақталған (Windows x64, Python 3.11). Жүктелген ірі пакеттер `.wheels/` бумасында
  орналасқан және Git-ке қосылмайды. Олардың SHA-256 мәндері ресми PyPI
  деректерімен салыстырылып тексерілді.
- FER-2013 бумаларының құрылымын тексеру, камера мен детекторды таңдау қосылды.
- Үздік модель `val_accuracy` бойынша сақталады. Тест жиынын бағалау бөлек орындалады.
- Әдістемедегі талапқа сәйкес камера кадрларын файлға сақтау алынып тасталды.
- FER-2013 берілген мұрағаттан шығарылды: оқытуға арналған 28 709 сурет,
  тестке арналған 7 178 сурет, барлығы жеті санат.
- CNN-ді алғашқы оқыту EarlyStopping арқылы 46-эпохада аяқталды (CPU, batch 64,
  seed 42). Ең жақсы сақталған модель — 38-эпоха, валидация дәлдігі **62,15%**.
  Оқытуға 24 403 сурет, валидацияға 4 306 сурет бөлінді. Бөліну тізімі
  `reports/data_split_seed42.json` файлында сақталған. Санат салмақтары тек оқыту
  жиыны бойынша есептелді. Оқыту кезінде тест жиыны жүктелмейді.
- Ең жақсы модельді 7 178 тест суретінде бағалау нәтижесі: **дәлдік 61,56%**
  (4 419 дұрыс жауап), macro F1 — **0,5713**, weighted F1 — **0,6064**.
  Нәтижелер мен модельдің SHA-256 мәні жергілікті
  `reports/metrics_emotion_cnn.json` файлында, толық есеп
  `reports/classification_emotion_cnn.txt` файлында сақталған.
  Қателесу матрицасы: `reports/confusion_emotion_cnn.png`;
  қате болжам мысалдары: `reports/errors_emotion_cnn.png`.
  Бағалау кезінде модель салмақтары өзгертілмеді.
- ZIP мұрағатының тұтастығы мен бумалар құрылымы тексерілді. Деректерді зерттеу
  жүйелік Python арқылы орындалды: `reports/class_distribution.png` және
  `reports/samples.png`.
- MobileNetV2 екі кезеңде оқытылды: негізгі желі бекітілген 10 эпоха және жоғарғы
  қабаттарды бейімдеудің (fine-tuning) 60 эпохасы. Ең жақсы валидация дәлдігі —
  **48,47%**, тест дәлдігі — **47,73%**. Бұл жобада CNN және MobileNetV2
  салыстырылады; екеуі де мұғаліммен оқытылады.
- Веб-камера арқылы көрсету жұмыс істейді. Gradio интерфейсі мен ойынның бастапқы
  коды бар; олардың оқытылған модельмен жұмысы әлі тексерілмеген.
- Бастапқы компьютерде деректер жергілікті мұрағаттан шығарылған. Репозиторийді
  көшіріп алған әр қатысушы FER-2013 жиынын төмендегі нұсқаулықпен бөлек алады.

## Модельдерді салыстыру

Екі модель бірдей оқыту және валидация бөлінуімен оқытылып, бірдей 7 178 тест
суретінде бағаланды. Үздік нұсқа валидация дәлдігі бойынша таңдалды.

| Көрсеткіш | CNN | MobileNetV2 |
|---|---:|---:|
| Ең жақсы валидация дәлдігі | 62,15% | 48,47% |
| Тест дәлдігі | **61,56%** | 47,73% |
| Macro F1 | **0,5713** | 0,4287 |
| Weighted F1 | **0,6064** | 0,4781 |

Осы тәжірибеде CNN тест дәлдігі бойынша 13,83 пайыздық тармаққа жоғары нәтиже
көрсетті және көрсетілім үшін негізгі модель ретінде қалдырылды. Бұл қорытынды
осы баптауларға қатысты; MobileNetV2 барлық жағдайда нашар дегенді білдірмейді.
Нақты нәтижелер мен модельдердің SHA-256 мәндері:
[салыстыру нәтижелері](reports/comparison_cnn_mobilenet.json).
Жеке метрикалар, жіктеу есептері, қателесу матрицалары және оқыту графиктері де
`reports/` бумасында жарияланған. Модель файлдары бөлек беріледі.

## Командамен жұмыс істеу

```powershell
git clone https://github.com/bakbergentoktarbek/facial-emotion-recognition.git
cd facial-emotion-recognition
```

Репозиторийді көшіргеннен кейін кітапханаларды орнатып, FER-2013 жиынын жүктеңіз.
Деректер жиыны, `.venv`, `.wheels` кэші, оқытылған модельдер мен оқыту журналдары
жергілікті компьютерде қалады және Git-ке қосылмайды. Оқытылған
`models/emotion_cnn.keras` және `models/emotion_mobilenet.keras` файлдары команда
мүшелеріне бөлек беріледі; алынған файлдарды `models/` бумасына орналастырыңыз.

Git-те `reports/data_split_seed42.json` сақталады: онда `data/fer2013` бумасына
қатысты жолдармен берілген оқыту және валидация файлдарының тізімдері бар.
Әдістерді салыстырғанда осы бөлінуді пайдаланыңыз. Валидация мен тест деректерін
оқытуға қоспаңыз. Қазіргі CNN скрипті seed 42 және көрсетілген кітапхана
нұсқаларымен осы бөлінуді қайталайды. CNN мен MobileNetV2 үшін бірдей файл
тізімдері пайдаланылады.

Өзгерістерді бөлек тармақтарда жасаңыз, мысалы:
`git switch -c feature/web-interface`. Оларды `main` тармағына pull request
арқылы біріктіріңіз.

## Орнату (жоба бумасындағы PowerShell)

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip --isolated install --index-url https://pypi.org/simple -r requirements.txt
.\.venv\Scripts\python.exe tools/check_environment.py
```

Ортаны белсендіру міндетті емес: командалар оның Python интерпретаторын тікелей
пайдаланады. VS Code ішінде `.venv\Scripts\python.exe` интерпретаторын таңдаңыз.
Windows-та осы ортаны нақты қалпына келтіру үшін `requirements.txt` орнына
`requirements-lock.txt` қолдануға болады. Colab үшін негізгі `requirements.txt`
файлын пайдаланыңыз. Қайта орнату кезінде `--find-links .wheels` параметрі бұрын
жүктелген пакеттерді пайдалануға мүмкіндік береді.

Екі бөлек OpenCV пакетінің орнына `opencv-contrib-python` қолданылады: ол `cv2`
модулін қамтиды және MediaPipe үшін қажет. Әдістемедегі мысалмен үйлесуі үшін
Gradio нұсқасы 5.x тармағымен шектелген. Windows-та камерамен жұмыс істеуге CPU
жеткілікті; модельді оқытуды Colab ортасына көшіруге болады.

## Алғашқы іске қосу: бетті анықтау

Камераны қосуға дайын болғанда мына команданы орындаңыз:

```powershell
.\.venv\Scripts\python.exe src/face_detect.py --detector haar
```

`M` пернесі Haar және MediaPipe арасында ауыстырады (MediaPipe қолжетімді болса),
`Q` терезені жабады. Камерамен мәселе болса, Zoom/Teams сияқты қолданбаларды
жауып, `--camera 1` параметрін қолданып көріңіз. Бұл скрипт кадрларды сақтамайды.
Детекторларды салыстыру үшін бет тура қарағанда, бас бұрылғанда, бет жартылай
жабылғанда және жарық аз болғанда олардың жұмысын бақылап жазыңыз.
Нәтижелерді жазуға арналған үлгі: `DETECTOR_COMPARISON.md`.

Әдепкіде бастапқы көрсетілімдегідей OpenCV камераны автоматты түрде ашады.
Windows-та қосымша нұсқа ретінде DirectShow қолданылады. Құрылғының ашылуы ғана
емес, одан кадрдың алынуы да тексеріледі. Эмоцияны тануды іске қосу:

```powershell
.\.venv\Scripts\python.exe src/webcam_demo.py
```

`Emotion model ready` және `Camera ready` хабарламаларын күтіңіз. TensorFlow-дың
oneDNN және CPU туралы ақпараттық хабарламалары камера қатесін білдірмейді.
Құрылғы кадр бермесе, бірнеше рет қайта оқылады, содан кейін қате хабарламасы
шығарылады. Іске қосылғанда кадрды бір рет оқи алмау көрсетілімді бірден жаппайды.
Терезені `Q`, `Esc` немесе жабу батырмасы арқылы жабыңыз; `Ctrl+C` кезінде де
камера босатылады. Модельге дейінгі бастапқы кадр қараға жақын болса, ескерту
шығарылады. Камераға қол жеткізу тәсілін қолмен таңдау үшін `--backend any` және
`--backend dshow` параметрлері бар.

## FER-2013 деректерін алу

Әдістемедегі деректер жиыны: [FER-2013](https://www.kaggle.com/datasets/msambare/fer2013).
Мұрағатты браузер арқылы жүктеуге болады. Ашық мұрағатты токенсіз жүктеу командасы:

```powershell
.\.venv\Scripts\python.exe tools/download_dataset.py
```

Kaggle сервері тіркелгіге кіруді талап етсе, браузер арқылы жүктеңіз.
Күтілетін құрылым:

```text
data/fer2013/
  train/
    angry/ disgust/ fear/ happy/ neutral/ sad/ surprise/
  test/
    angry/ disgust/ fear/ happy/ neutral/ sad/ surprise/
```

Бұлар — ішінде суреттері бар бөлек санат бумалары. Артық `fer2013/fer2013/`
қабаттасуын жасамаңыз. Деректер жиыны мен Kaggle токендерін Git-ке қоспаңыз.
Kaggle CLI бапталған болса, мына балама команданы қолдануға болады:

```powershell
.\.venv\Scripts\kaggle.exe datasets download -d msambare/fer2013 -p data/fer2013 --unzip
```

Деректерді зерттеу үшін:

```powershell
.\.venv\Scripts\python.exe src/data.py
```

Нәтижелер: `reports/class_distribution.png` және `reports/samples.png`.
Сирек кездесетін санаттар да көрінуі үшін сурет мысалдары әр санаттан бөлек алынады.

## CNN моделін оқыту

`tools/start_training.py` арқылы фондық режимде іске қосқанда процесс нөмірі (PID)
мен команда жергілікті `reports/training_run.json` файлында сақталады.
Бастапқы компьютерде алғашқы оқыту аяқталған. Басқа компьютерлерде оқыту
автоматты түрде басталмайды. Бір компьютерде екі оқыту процесін қатар қоспаңыз.
Күйі: `reports/status_cnn.json`; журнал: `reports/training_cnn.log`.
Әр аяқталған эпохадан кейін мына файлдар сақталады:

- `models/emotion_cnn.keras` — валидация дәлдігі бойынша ең жақсы модель;
- `reports/training_cnn.csv` — әр эпоханың көрсеткіштері;
- `reports/history_cnn.json` және `reports/history_cnn.png` — оқыту тарихы мен графиктері.

EarlyStopping валидация дәлдігі 8 эпоха бойы жақсармаса, оқытуды тоқтатады.
`val_loss` жақсаруы тоқырағанда оқыту қадамы (learning rate) азаяды.
Оқытуды қолмен бастау командасы:

```powershell
.\.venv\Scripts\python.exe src/train.py --model cnn --epochs 60 --batch 64
```

MobileNetV2 оқытуды бөлек іске қосу (алғашқы 10 эпохадан кейін `--epochs` санына
дейін fine-tuning орындалады):

```powershell
.\.venv\Scripts\python.exe src/train.py --model mobilenet --epochs 60 --batch 64
```

Параметрлер валидация нәтижесі бойынша таңдалады. Тест жиыны қорытынды бағалау
үшін пайдаланылады. Бағалау, камера, веб-интерфейс және ойынды іске қосу командалары:

```powershell
.\.venv\Scripts\python.exe src/evaluate.py --model models/emotion_cnn.keras --no-show
.\.venv\Scripts\python.exe src/webcam_demo.py
.\.venv\Scripts\python.exe src/app_gradio.py
.\.venv\Scripts\python.exe src/game.py
```

Бұл командалар үшін сақталған модель файлы қажет. Қорытынды көрсетілімде оқыту
аяқталғаннан кейінгі ең жақсы модельді пайдаланыңыз. Интерфейс пен ойында
әдістемедегі қазақша жазулар сақталған. Windows-та Arial қарпі қолданылады;
балама ретінде `DejaVuSans.ttf` файлын `fonts/` бумасына орналастыруға болады.

## Екі апталық жоспар

Бірінші апта: ортаны дайындау, деректерді зерттеу, CNN оқыту және камерамен жұмыс.
Екінші апта: MobileNetV2 оқыту және CNN-мен салыстыру (аяқталды), веб-интерфейс
пен ойынды тексеру, есеп пен қорғауды дайындау.
